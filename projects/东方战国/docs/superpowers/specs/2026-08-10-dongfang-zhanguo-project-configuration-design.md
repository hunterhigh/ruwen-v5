# 《东方战国》项目配置与第一章修订设计

## 目标

将用户提供的《东方战国》压缩包配置为可持续创作的本地小说工程，补齐主角饶景行的正式人物基础和微生物安全能力，并在不改变既定开篇事件与详细物资结算的前提下重写第一章候选稿。

## 项目安装

- 项目根目录固定为 `C:\Users\admin\Desktop\Main2\东方战国`。
- 原始压缩包保持不变，作为可回溯的来源备份。
- 解压时去除压缩包自带的顶层目录，并修复 ZIP 旧编码造成的中文文件名乱码。
- 不初始化 Git，与工作区内现有小说项目保持一致。
- 保留模块化目录，不合并正典、提案、人物镜头、叙事指令和校验规则。
- 补齐新版工作流所需但当前缺失的空目录或操作文件，例如 `cold-reads/`、`author-voice/relationship-lenses/` 和空的 `arc-shape-ledger.json`；不借此创造新正典。
- 在项目 `AGENTS.md` 中增加持久规则：本项目不得使用子 Agent 进行写作、审读或改稿。

## 主角正式设定

主角正式定名为饶景行。以下内容进入正式人物档案和连续性记录：

- 二十多岁的普通现代年轻人，毕业于较好的大学，进入较好的工作平台。
- 热爱学习，喜欢深入钻研问题，追求进步，并希望建立属于自己的事业。
- 不擅长人际关系，性格偏孤僻；不天然懂得人心、权谋、政治或领导。
- 善于观察和学习平台规则，能够凭可靠产出、自我约束和适应能力在大型组织中生存。
- 有精英主义倾向，尊重能力、纪律与成果，对低效和不负责任缺乏耐心。这是其优势，也是长期统治成长必须面对的局限。
- 喜欢艺术，对器物、建筑、构图、色彩、仪式和形式之美有感受力，但具体艺术门类暂不锁定。
- 高度自律，能够长期承受重复、枯燥和严格训练，这是他被选入高机能士兵改造试验的重要原因。
- 接受军事训练不等于接受杀人。他具备战斗动作、威胁判断和条件反射，但仍保留普通年轻人面对真实死亡时的恐惧、恶心、内疚与自我怀疑。
- 初期优势是观察、学习、自律和在大平台中存活；用人、权谋、政治判断与统治能力必须在异世界经历中逐步养成。

具体大学、专业、公司、职位、家庭背景、试验招募方式及艺术偏好仍保持未决，不在本次修订中擅定。

## 微生物伏笔

- 饶景行的改造身体能够自动进行必要的微生物环境调节，避免他轻易成为感染整个星球的病原源，也增强穿越设定的严谨性。
- 第一章只简短写到身体已经开始相关调节，以及饶景行意识到异星人群之间可能存在微生物风险；不展开检测流程、风险模型或生物学说明。
- 身体会在特定隔离部位保留少量原世界细菌或病原体，使饶景行以后仍有条件取用。
- 这些留存物当前只作为受保护伏笔存在；具体保存位置、种类、用途和启用后果暂不决定，也不在第一章解释。

## 第一章修订范围

采用“同事件重写”，而不是在旧稿上零散补句。

必须保留的事件与成果：

- 饶景行在赣南山地赤身苏醒。
- 他确认身体状态，寻找水源和最低限度的生存条件。
- 他发现并观察一场具有长枪、弓、火绳枪、家徽、旗阵和本阵的局部战争。
- 他遭遇一名脱离战场的武装者，无法通过语言完成沟通，冲突升级。
- 他取得本地衣物、鞋履或代用品、长短武器、水具、火具、食物、钱币和带身份痕迹的物品。
- 保留现有战利品的种类、数量与详细物资结算功能；只允许为人物反应和前后衔接做必要修改。
- 章末仍走向可能存在村落、庙宇或其他人烟的炊烟，为第二章山中小庙建立自然连接。

需要重写的体验：

- 开头不再以长篇生理检测支配阅读，而从饶景行醒来的混乱、羞耻、求生欲、学习习惯和控制欲展开；身体能力通过他要完成的具体动作显现。
- 保留他对地形、武器和军队的专业观察，但避免让战场成为军制说明书；观察必须持续改变他的危险判断、时代判断和接近人群的决定。
- 艺术感受只在真实视觉矛盾中出现，例如旗阵与甲胄构图的美感和近处伤亡的冲突，不写成作者评论。
- 他不会因会格斗便自然接受杀人。遭遇中先出现回避、手势沟通和制服意图；犹豫使风险逼近，强化身体与本地人体耐受差异又使控制失败。死亡不是战利品触发器。
- 死亡后的应激不能立刻被理性复盘覆盖。血液、尸体温度、取衣、进食、清洗和再次听见人声都会使反应回返，并改变他的动作。
- 微生物风险只在饮水、接触血液、穿死者衣物或准备接近人烟时被简短触发；身体自动完成必要调节，并提示仍有少量原世界菌原留存在特定隔离部位，不展开说明。
- 保留章末具体物资结算，同时让清点承担现实功能：确认能否继续行走、避免暴露身份、控制污染并恢复行动，而不是系统奖励播报。

## 版本与批准边界

- 原第一章完整保留为 `drafts/chapter-001-draft-v1.md`。
- 重写稿使用现行路径 `drafts/chapter-001-draft.md`，状态保持 `awaiting-user-approval`。
- 重写稿在用户明确批准前不得复制到 `chapters/`，不得作为第二章已经发生的事实，也不得更新章后连续性。
- 饶景行的姓名、用户明确给出的性格基础和微生物能力可以作为本轮已批准设定写入正式人物档案；正文新增的具体经历仍需单独批准。

## 单上下文工作流

依照用户要求，本项目不使用子 Agent。人物设计、正文重写、情感审读、文学编辑和连续性检查均在当前任务中顺序完成。

这会降低创作角色之间的真实上下文隔离，因此：

- 不声称冷读结果来自完全独立的读者上下文。
- 各阶段使用单独的临时文件和明确的输入边界，尽量减少审读规则对初稿生成的污染。
- 最终仍以用户对具体草稿的明确批准作为唯一正典化依据。

## 验证

- 检查解压后的文件名、目录结构、JSON 语法和内部路径引用。
- 检查旧稿已完整备份且新稿未进入正式章节。
- 计算新稿中文非空白字符数；硬下限为 7000，目标约 10000，无硬上限。
- 对照已批准正典检查时间、地点、知识来源、身体限制、装备来源与受保护未知。
- 检查饶景行没有提前获得语言、权谋、统治或全知式微生物知识。
- 检查详细物资结算及其物品数量没有被删除或无声更换。
- 检查项目内已写入禁止子 Agent 的持久协作规则。
