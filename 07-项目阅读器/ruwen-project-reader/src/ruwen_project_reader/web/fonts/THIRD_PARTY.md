# 随附字体

本目录中的字体仅供 Ruwen 项目阅读器离线显示使用，均保留原始许可文件。

- `noto/`：Noto Serif SC，来自 `@fontsource/noto-serif-sc@5.3.0`，SIL Open Font License 1.1。
- `xiaowei/`：ZCOOL XiaoWei（站酷小薇体），来自 `@fontsource/zcool-xiaowei@5.3.0`，SIL Open Font License 1.1。
- `wenkai/`：LXGW WenKai（霞鹜文楷），来自 `lxgw-wenkai-webfont@1.7.0`，SIL Open Font License 1.1。

字体文件与应用一同保存在本地，不会从外部网络加载。
