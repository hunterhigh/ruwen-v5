# Ruwen 项目阅读器实施计划

日期：2026-09-04
设计依据：`docs/superpowers/specs/2026-09-04-ruwen-project-reader-design.md`

## 实施边界

新组件位于 `07-项目阅读器/ruwen-project-reader/`，只修改 `v5ruwen` 仓库。组件不依赖 `sat` 根目录运行代码，也不修改现有 Ruwen 插件、项目模板或用户小说项目。

正式运行时只写选定项目的 `.ruwen/` 与封存快照 `治理/批注/`；测试使用临时项目副本。

## 任务一：建立独立 Python 组件骨架

创建：

- `pyproject.toml` 与 `README.md`；
- `src/ruwen_project_reader/` Python 包；
- `web/` 本地前端资源目录；
- `tests/` 自动化测试目录；
- 字体许可证与第三方资源说明。

启动入口为：

```powershell
python -m ruwen_project_reader --project <项目目录>
```

仅使用 Python 标准库，要求 Python 3.11 或更高版本。先写包结构测试，再建立最小可启动服务。

## 任务二：实现安全项目读取层

先写失败测试覆盖：

- 支持文件类型；
- `.git/`、`.ruwen/`、缓存与二进制目录过滤；
- 路径穿越和符号链接逃逸拒绝；
- 文件大小上限；
- UTF-8 与常见 BOM 读取；
- 文件哈希稳定性。

实现 `project.py`，输出真实目录树并按相对路径读取文件。项目名默认使用根目录名。

## 任务三：实现 SQLite 批注与批次核心

先写失败测试覆盖：

- 数据库初始化和迁移版本；
- 首个草稿批次与单调编号；
- 批注新增、编辑和删除；
- 封存后不可修改；
- 重启后状态恢复；
- 多请求事务安全。

实现 `database.py` 与 `annotations.py`。数据库固定写入 `.ruwen/control.sqlite3`，连接开启外键与 WAL。

## 任务四：实现锚点恢复与封存快照

先写失败测试覆盖：

- 哈希相同的精确恢复；
- 文件变化后的选中文本恢复；
- 标题链与前后文辅助恢复；
- 多个候选或无候选时标记“需要重新定位”；
- 快照稳定排序、原子写入和哈希；
- 已有快照禁止覆盖；
- 封存失败时事务回滚。

实现 `anchors.py` 与 `snapshots.py`。封存成功后自动创建下一草稿批次，并生成 Ruwen 处理说明。

## 任务五：实现 Git 版本读取

先写失败测试覆盖：

- Git 项目文件历史；
- 指定修订内容读取；
- 两版本统一差异；
- 非 Git 项目降级；
- 非法修订和项目外路径拒绝。

实现 `git_history.py`，只调用只读 Git 命令，不改变工作树、索引或分支。

## 任务六：实现本地 HTTP API 与安全会话

先写 API 集成测试覆盖：

- 会话令牌缺失或错误时拒绝；
- 项目概览、文件内容、批注和批次接口；
- 封存接口的成功与错误语义；
- 静态资源只从组件 `web/` 读取；
- 所有响应使用明确 JSON 与 UTF-8；
- 服务只绑定回环地址。

实现 `server.py` 和 `__main__.py`。启动时选择随机端口、生成随机令牌并打开浏览器；测试模式禁止自动打开。

## 任务七：实现已批准的阅读器界面

按视觉规格实现：

- 左侧真实文件树与搜索；
- 中间阅读、源文、版本三视图；
- 右侧锚点、批注输入与本文批注；
- 底部当前批次与批次抽屉；
- 桌面、中等宽度与小屏布局；
- 无卡片、阴影、渐变和装饰图形。

Markdown 在浏览器中使用受限渲染器：先转义原始 HTML，只解释标题、段落、列表、引用和代码块，禁止脚本与任意 HTML 注入。

交互验收包括：文件切换、文本选择、批注发送、草稿编辑、批次查看、封存、版本列表和错误提示。

## 任务八：自托管字体与字体加载校验

引入并固定：

- 站酷小薇体；
- 霞鹜文楷；
- 思源宋体。

保留每款字体的许可证、版本和来源。使用 WOFF2 子集与 `unicode-range`，不请求网络资源。启动自检验证 CSS 与字体文件齐全；浏览器端等待 `document.fonts.ready` 后移除加载状态，失败时显示错误而不是静默回退。

## 任务九：端到端验证与文档

建立临时 Ruwen 项目，验证：

1. 打开文件并保持真实目录层级；
2. 选择文字并跨文件加入同一批次；
3. 重启恢复批次；
4. 修改原文件后出现重新定位状态；
5. 封存生成不可变 JSON；
6. 新批注进入下一批；
7. Git 与非 Git 项目均可使用；
8. 项目正文没有被写入；
9. 页面在三个响应式宽度下可用；
10. 断网后字体和全部功能仍然工作。

README 写明安装、启动、数据位置、备份、恢复、卸载和安全边界。

## 提交顺序

1. `test: define project reader contracts`
2. `feat: add secure Ruwen project access`
3. `feat: add annotations and immutable batches`
4. `feat: add local reader API`
5. `feat: build Ruwen project reader interface`
6. `test: verify reader end to end`

每次提交只包含当前组件或对应设计文档，不纳入现有项目商业顾问 submodule 的工作区修改。
