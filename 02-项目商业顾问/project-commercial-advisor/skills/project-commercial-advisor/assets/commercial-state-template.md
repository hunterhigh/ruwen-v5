# 项目商业状态

## 当前经营决策

记录用户最近批准的立项、继续、调整、追加投入、降低投入、暂停或停止决定，以及决定日期。

## 仍有效的关键商业判断

只记录仍会影响下一次经营决策、且尚未被证据否定的判断。注明其依据是事实还是待验证假设。

## 已被削弱或否定的判断

简要记录原判断、改变其状态的实际证据和判断日期，避免事后改写立项逻辑。

## 用户批准的投入与风险边界

记录时间、资金、工具、外包和机会成本等已批准边界，以及用户不愿牺牲的价值。

## 当前需要验证的问题

记录能够改变当前经营决定的最小下一证据。不保存泛化研究待办。

## 更新约束

- 顾问只提出变更预览；用户批准后才更新经营决策或投入边界。
- 不复制市场研究全文、竞品材料、长篇推理或全量后台数据。
- 不写章节、故事或编辑规则。
