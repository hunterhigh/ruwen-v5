# 长期叙事指令

## 每次写正文前

1. 读取已批准正典、当前阶段计划、连续性记录和涉及人物档案。
2. 确认场景的绝对时间、相对上一场经过多久、人物从何处来、需要多少行程。
3. 确认在场者各自知道什么；不得把作者知识下放给人物。
4. 为每名长期角色选取一至两个稳定外貌特征在行动中重现。
5. 明确场景快感：武勇、用人、归属、政治抉择、战争压力或领地成长，至少有一项发生实质变化。

## 写作中

- 单一人物限知为默认视角；切换视角必须伴随明确场景转换。
- 先呈现可感知事实，再允许人物解释；人物解释可以错。
- 身体强化通过呼吸、热量、疼痛、血流、爆发后的恢复和营养需求表现，不显示游戏面板。
- 饶景行受过军事训练，但没有杀人心理准备。第一次及后续早期杀人不能被写成顺手完成的技术动作；死亡应改变他的身体反应、注意、选择和与他人的距离。
- 饶景行在三木集团轮岗时习惯通过提前到场、观察具体工序和承担可验证的工作取得位置，但不自动理解本地人心、权谋、政治与统治。他可以形成假设，也必须允许误判、迟悟和被他人教育。
- 微生物调节只在场景真正涉及异地接触、污染或后续取用时简短出现；身体特定隔离部位留存的原世界菌原在用途获批前保持后台。
- 现代知识只在主角确实掌握且当地条件可支持时有效。
- 战场命令会被风、距离、地形、旗指误判和传令伤亡扭曲。
- 本阵既是视觉中心，也是主君可能被识破、包围和动摇全军的危险所在。
- 武士、浪人、带刀、家徽、本阵可以直接出现；不要替“武士”发明统一法定等级。
- 同一阵营允许装备杂色，但主家旗物与核心武士的造型必须可辨。
- 对话中的古意来自称谓、礼序、句子分寸与回避，不来自通篇半文言。

## 第十五章起的武艺成长

- 罗翁从第十六章开始测试饶景行的力量、体能、爆发、敏捷、速度、平衡、恢复、精细控制与左右侧差异；测试通过采药、修路、负重和竹杖训练进入正文，不写成体测表。
- “负山架”是作者后台暂名：主手单手持刀横在脑后，另一手自然垂下；姿势粗野、懒散、正面开放，不是标准双手上段。
- 刀法的核心表现为主动进攻靠力量、主动防守靠敏捷、防守反击靠速度。正文以躲避、回刀招架、招架后立即还击的身体过程呈现，不直接复述后台总结。
- 第二十九章以前，罗翁的教学看似无系统，是因为他不解释、不命名并不断改变训练条件。第二十九章起，他在拒绝正式收徒后开始用两把旧木刀系统整理传授；系统性通过动作之间终于连通、目标变化和旧木刀交付显形，不写成课堂目录。
- 山庙修行使用可见小说锚点承载阶段变化：木刀断叶、活人灰痕、第一次不追诱饵。锚点必须处在有人想赢、想偷看、怕丢脸、要叫孩子回家或必须处理庙务的生活场景中，不报告每日次数和训练进度。
- 陶杏、其母亲、来庙村人、烟味、饭食、药架与虎迹会真实打断和改变修行。修行不是与乡村生活隔绝的技术空间。
- 饶景行可以因速度足够快而从脑后回刀招架，但不能稳定躲过一切攻击；枪阵、远程武器、多人夹击、狭窄地形、疲劳、饥饿和主手伤势始终有效。
- 空闲手可以推、抓、控械、扶持或携物；持旗只是一种未来可能，不是负山刀法的起源，也不锁定主角永久成为旗手。
- 第十五章的屈辱余波必须保留普通人的哭泣、创伤和失去安全感，不得立即转换成冷酷、权谋成熟或称霸宣言。

## 写作后

1. 更新日期、位置、伤势、随身物、军粮、身份和人物关系。
2. 检查是否误用了章节元叙事或现代组织术语。
3. 检查对话是否人人同样聪明、同样简练、同样喜欢反问。
4. 检查颜色是否只在真实视觉与军事实用中工作。
5. 检查胜利是否有可信的执行过程；失败是否源于人物与条件，而非作者强迫。
6. 新设定只进入提案层；经作者批准后才能写入正典层。

## 长篇推进纪律

- 不提前为主角锁定全部家臣、婚姻、国号、帝号和统一路线。
- 主角的精英主义既能推动自律、学习和事业欲，也会妨碍他理解能力有限、依赖关系或不以成果衡量自身价值的人；不要提前替他完成这部分成长。
- 历史大势按事件压力推进，不按“第几章必须灭谁”推进。
- 每次身份跃升必须被他人承认，并通过称谓、座次、护卫、衣甲、居所、婚姻资格或发令范围体现。
- 每次领地扩张都带来新的地方人物与旧秩序，不能只增加地图面积。
- 家臣成长既包括武功和职位，也包括家室、门生、私怨、疾病、老去与继承人。
- 统一不是故事自动正确的终点；不同人物应对“天下一统”有不同利益和道德判断。
