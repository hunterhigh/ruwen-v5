# 信息与岗位隔离合同

## 六种白名单交接物

系统只允许：创意委托、外部顾问任务书、资料治理预览、表现能力候选、当前章节情境、批准后的记忆变更预览。

交接物必须标明接收岗位、来源资源ID、作用域、状态和审批；不得夹带原始用户消息、治理解释、研究来源清单、编辑投诉、盲评、失败日志或其他岗位内部推理。

交接创建阶段对每种payload使用精确值类型和有界嵌套，并以内存中的当前原始表达做长片段重合检查。原文不落盘；执行阶段只读取已批准快照和独立批准事件。

## 读取矩阵

| 岗位 | 可读 | 不可读 |
|---|---|---|
| 创意协调员 | 用户当前表达、最少项目状态 | 下游成稿策略、编辑问题全文 |
| 项目治理员 | 全部权威资料、注册表、审计统计 | 小说作者私有生成过程、投诉原话 |
| 外部知识顾问 | 任务书、章程、相关人物世界、弧线目的、批准样本 | 作者包、编辑历史、盲评、失败日志 |
| 表现设计师 | 已批准研究与正文、项目结构、作用域 | 原始投诉、未批准研究、故事答案 |
| 故事构思师 | 创意委托、相关人物世界、当前故事状态 | 研究原文、作者包、编辑账本 |
| 章节情境编译员 | 批准故事、当前状态、有效世界和Canon | 研究原文、编辑诊断、完整用户对话 |
| 小说作者 | 编译后的作者资料包 | 人物世界全文、故事大纲、研究治理校验 |
| 情感读者 | 正文、最少阅读定位 | 大纲、检查表、来源 |
| 文学编辑 | 当前候选正文、读者反应、面向该候选的创意委托、单项按需诊断 | 小说作者包、治理解释、跨章设计 |
| 两类核验员 | 正文与各自核验材料 | 写作规则、编辑投诉 |
| 记忆维护员 | 批准正文、变更预览、权威资料 | 未批准候选的推断 |

## 防双重输入

同一接收岗位不得同时获得原始输入和经过转换的交接物。隔离运行的上下文只包含当次岗位任务；上一岗位的推理与评语退出。

## Silent floor

系统可以在后台完成治理、来源和核验，但不得把这些过程写进小说。正文不展示约束、来源、权威层级、审计证明或“我已经履约”的防御性语言。
