# 项目协作约定

- 保留本项目的模块化目录，不把 `proposals/`、`world/`、人物镜头和校验规则合并成一份总设定。
- 用户已批准的事实才能进入 `world/`、`story-bible.md` 和正式人物档案。
- 新增国名、家族、历史结局、人物关系和战争结果先写入 `proposals/`；不得仅因设计完整便自动升级为正典。
- 正文直接使用武士、浪人、带刀、家徽和本阵；不要为武士创造法定等级表或身份注册系统。
- 中国本土地理是固定基底。设计资料可使用“华北平原”等现代地理标签，正文人物应使用符合世界时代的地域称呼。
- 政治称谓和对话参考春秋战国的身份距离；军事组织和战场视觉允许明确吸收日本战国。
- 不把小说写成制度说明书、军事编制表、逻辑推演日志或现代政治学教材。
- 未经批准不生成正文；候选正文不得进入连续性正典。
- 本项目的正文写作、审读与改稿不得调用子 Agent；需要区分创作阶段时，在当前任务中顺序执行，并明确承认上下文隔离有所降低。
