# 东方战国（工作名）

一部以中国本土地理、春秋战国式称谓、日本战国式武士文化与战争组织为基础的异世界争霸长篇。

主角饶景行来自科技世界，毕业于联邦大学系统工程专业，随后进入三木集团总部管培序列，在制造、供应链和新业务相关岗位轮岗。他热爱学习和钻研，追求自己的事业，不善人际，兼有精英主义、艺术爱好和高度自律。三木集团公开参与军工并经营民用技术；他知情自愿参加军民两用人体强化实验，希望提前进入产品过程，并在新事业部门参与业务拓展。他拥有能够主动调节营养摄入、血液流动、代谢、痛觉和身体状态的意念操作系统，也接受过格斗、射击及军事训练；这些训练不等于杀人心理准备，也不会让他天然理解权谋。转移途中遭遇星际风暴，低温休眠仓坠落到这个世界。世界与历史仍按提案逐层批准；赣南开局及前两章方向已经初始化。

本项目参照《铁潮前夜》采用逐层批准：

- `world/`：用户已经批准的世界规则与正式索引；
- `proposals/`：完整候选设计，未经批准不得冒充正典；
- `story-bible.md`：项目不变量与正典入口；
- `continuity-ledger.md`：批准来源、受保护未知与长期状态；
- `open-threads.md`：尚待决定的问题；
- `characters/`：获批准的人物事实与人物镜头；
- `author-voice/`：项目声音、视角和场景模式；
- `prose-basis.md`：正文快感、语言和反模式；
- `narrative-directives.md`：长期创作边界；
- `validation-rules.md`：完整草稿完成后的硬性校验；
- `research/`：现实历史、军事和视觉参考的提炼；
- `drafts/` 与 `chapters/`：候选正文与批准正文；第一至第五章已经批准归档，目前没有活动候选稿。

## 当前批准基准

1. 文化与天下观以中华为主，日本战国为辅。
2. 地理直接使用中国本土地理，使华北平原、关中、河西、赣南、江汉、吴越及重要关隘具有读者熟悉的战略意义。
3. 政治称谓和对白气质主要取自春秋战国，但不是严格历史复原。
4. 正文直接使用“武士”“浪人”“带刀”“家徽”“本阵”等概念，不把武士制造成边界整齐的法定阶层。
5. 军队与作战采用日本战国式封建联军、家臣部队、城砦争夺、长枪、弓、鸟铳、骑马武士、旗本与浪人众。
6. 家族有稳定家徽和战场主色；著名武士拥有风格化个人铠甲、头盔、阵袍、旗号和马具。
7. 战场视觉追求黑泽明电影式的远景色块、旗帜运动、天气与地形，同时在近景保留恐惧、泥泞、伤亡和身份崩塌。
8. 世界没有修仙与稳定魔法体系。“巨人之怒”只是七十年前自然灾害的传说名称，而且不是天下分裂的主要原因。
9. 天下名义上仍奉都城天子；至少五个强国已经称王，另有公侯、卿族、城主、国人众治之地、宗教势力、归化部族和西方汗国。
10. 开场附近至少有三十个可独立行动的势力，随后会因兼并、继承、归附、内乱与灭国逐渐整合。

## 当前建设顺序

1. 中国地理上的列国与战略区；
2. 王室衰微、五王并立与七十年历史；
3. 三十势力的政治来源和相互关系；
4. 武士、家臣、浪人、军队编成与战场视觉；
5. 六十二项历史事件与十项开场后历史压力；
6. 开场时代群像；
7. 主角降落区域与第一卷范围；
8. 正文项目。

## 已初始化开局

- 第一章《山中有兵》已批准：赣南山地赤身求生，继而观察战场与技术时代，在第一次真实杀人后取得衣物、武器和第一批财产，并进行具体物资结算。
- 第二章《山庙哑客》已批准：进入山中小庙，以哑巴式交流和主动劳动请求收留，开始接触当地生产生活。
- 第三章《柴水之间》已批准：在七日庙中生活里逐步学习语言、适应劳动与附近人群，章末获得随村妇下山的有限许可。
- 第四章《石梁城下》已批准：进入顾氏控制的石梁城，确认行山公祭祀，取得旧蒙书《百物》，并通过支沟鱼篓主动补充食物。
- 第五章《瓦下人声》已批准：语言退到生活背景，饶景行通过捕鱼、换取旧料、局部修庙和雨夜检验承担固定庙务；老人只确认姓罗，双方仍保留来历。

分章情境位于 `situation-seeds/`。自第三章起，每章一万字为硬下限，自然目标约一万一千至一万三千字，没有硬上限；已经自然完成的长稿不因长度缩减。第二章是规则调整前获批的历史例外。
