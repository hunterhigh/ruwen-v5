# 如文·故事构思

## 目标

把用户的创造力、项目事实和必要知识转化为可保存的项目资料或当前章节情境，同时不把开放文学问题封闭成执行路线。

开始前完整读取同目录的 `CREATIVE-SOUL.md`。按任务需要读取参考文件；不得把参考文件整包交给下游。

## 入口路由

1. 任何新增剧情、设定、人物心理张力、项目声音、领域写法或研究请求，先由**创意协调员**处理。
2. 项目尚未初始化或资料发生结构变化时，交给**项目治理员**。
3. 需要外部现实或文学材料时，交给**外部知识顾问**；没有明确问题时先给学习计划，获得批准后再调查。
4. 需要把批准材料变成项目文字能力时，交给**表现设计师**。
5. 跨章与章节内容由**故事构思师**与用户共同形成。
6. 正式写作前由**章节情境编译员**生成 generation field。

这些是隔离岗位。每个岗位只接收白名单交接物和必要权威资料；不得让同一岗位同时看到用户原话与翻译后的委托。

## 创意通讯门

执行任何创意写入前，先给用户一份简短自然语言预览：

- 真正要保留的创意价值或戏剧压力；
- 用户已经固定的事实；
- 仍应开放给下游的实现与理解；
- 示例是否只用于说明功能；
- 资料归属、作用域和将运行的岗位。

用户确认后形成一次性干净委托。遵守 `../../shared/creative-communication-contract.md`。简单请求可以把理解预览和修改预览合并，但不得跳过确认后直接改项目资料。

## 项目初始化

正式章节生产前必须完成：

- `项目/项目章程.md`；
- `人物/主角档案.md`的客观存在、内在组织、叙述接口三部分；
- `世界/世界总表.md`和支持主角现实生活的核心系统；
- `世界/当前态势.md`；
- `表现/项目声音.md`至少为已批准的最小版本；
- `治理/资源注册表.json`、`治理/审计账本.jsonl`和项目状态。

初始化不是填满模板。遇到会改变整部小说但用户尚未决定的空白，以假说和选择补问；确认不了的内容保留开放，不能用通用人物性格或世界百科补齐。项目就绪由 `../../scripts/project_readiness.py` 检查。

## 人物、世界与故事

- 人物资料按客观事实、自我理解、他人看法和开放未知分开。精神或感知异常必须写清经验、解释、可靠性认识、变化条件、行动影响、他人知情和不确定部分。
- 世界系统写运行关系，不写百科主题文章。一次研究结果必须归入既有系统或先通过治理预览建立正式系统。
- 故事设计可以明确事件和后果，但不预写对白、意象、最终心理结论、读者感受或结尾画面。
- 用户明确“必须发生”的事实与顺序可以锁定；普通创意方向不能自动升级为锁定项。

详细规范见 `references/project-knowledge-model.md`、`references/story-construction.md` 和 `references/scope-and-governance.md`。

隔离岗位运行前按职责读取 `references/roles/` 中与本次岗位同名的单个文件；不得一次加载全部岗位文件。

## 研究与表现能力

外部知识顾问只产出证据、观察、机会、冲突和归属建议；不得直接写Canon、大纲、项目声音或作者规则。表现设计师只能使用已批准材料，并在激活前运行闭合风险审计。见 `references/external-knowledge-and-expression.md`。

## 编译当前章节情境

章节情境编译员按以下顺序工作：

`主角当前状态 → 当前故事压力 → 有效世界系统 → 相关Canon → 当前场景接触`

generation field只写：

1. 时间、地点、身体、物质条件和正在进行的活动；
2. 活跃人物此刻做什么、想要什么、回避或误解什么；
3. 必须发生的可观察事件和用户锁定顺序；
4. 未解决压力与仍开放的选择。

世界条件只在其改变动作、成本、感知或误认、当地社会含义、环境或制度自身运动时进入。做一次“通用布景反事实”，但没有相关条件时不得硬添质感。总长度不超过2,200字符。

禁止进入：规划理由、人物最后理解、对话问答、预定意象、固定表情、结尾画面、注意力检查表、研究来源和编辑诊断。

## 写入与交接

- 所有项目资料变更先生成治理预览，用户批准后才写入。
- 创意委托保存为待批准快照前，使用 `../../scripts/handoff_validator.py --creation-check`，从标准输入提供当前原始表达；原文只参与重合检查，不写入快照。创建检查未通过时不得人工绕过生成交接文件。
- 正式写入同时更新资源注册表与审计账本。
- 交给章节写作入口的唯一创作交接物是“当前章节情境”；研究来源、治理说明和原始请求退出上下文。
- 研究或表现资源仍为 `candidate` 时不得装入作者资料包。
