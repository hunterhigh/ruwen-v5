# 第二十四章现实与连续性检查

结果：PASS

- 时间：开篇从第二十三章最后一句直接接续，同一场暴雨夜；孙宗弼交手、樊岳追击发生在敌军撤退期，随后自然跨至雨后白日与第二日赏钱发放。
- 地形：步战发生于窄田埂、水沟与软红泥间；樊岳只沿较硬高埂保持马速，不让坐骑在深水田中不合理冲锋。
- 孙宗弼：交手前主角不知道姓名；死后由樊岳随从与顾氏低阶武士依据脸、前立认出。其速度、力量不及主角，但从未硬挡全力重刀，以落脚、诱击、断枪、尸体和田埂高差完成公开击倒。
- 失败结果：饶景行未故意让败、未先伤孙宗弼；面朝下入泥、旧刀脱离有效控制、白皮滑眼，右大腿外侧受浅刀伤。孙宗弼因追兵靠近与撤退任务而未取首，逻辑成立。
- 樊岳讨取：从斜后硬埂不停马接近，以长枪刺入右腋甲片下至侧背；孙宗弼仅能使枪杆偏移，不能重置地形或进入第二次刀战。主角没有为此击杀制造伤势。
- 战功：主角实际杀五人；只核验第三、第四、第五名普通足轻。程介、陆槐和石梁人员分别完成见证链；沈砺未被强行拉入结算。
- 奖励与身份：三项普通足轻功得到约可买两至三个月粗粮的有限赏钱；无刀、甲、马、家徽、俸禄、武士称谓、带兵权或足轻编制。谢垣斥离位，谢岱接受本馆功劳，主角继续为役夫并受三日头班轻罚。
- 兵器：三道护手浅痕的旧刀因标记被北边一座小馆认领，归阵亡原主之家；主角未据为己有。
- 伤势与身体：左上臂与右大腿均为浅伤，仍可劳动但会疼痛、渗血和跛行；饥饿贯穿交手与战后，未以身体调节抹除食物、休息和感染风险。
- 信息边界：主角不知道敌军总数、完整撤退命令、联军全局伤亡和上层判断；战后消息保持役夫与足轻口耳传闻状态。
