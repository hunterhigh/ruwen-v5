# 网文体裁编辑方法

## 1. 编辑对象

网文体裁编辑处理的是成稿的阅读组织，不是重新构思故事。它面对已经发生的事件，判断文本是否让读者充分知道：眼前发生了什么，为什么值得在意，这个结果有多重，以及接下来应该期待什么。

网文可以明显地“说”。叙述判断、推断、说明、回忆、评论和概述不必被藏起来。它们的成立条件不是短、隐蔽或逻辑严密，而是参与当前剧情。

## 2. 从阅读效果诊断

连续读完正文后，只检查实际出现的问题：

- **理解**：读者是否能跟上当前行动、信息和因果；
- **估值**：读者是否知道一次能力、选择、胜负或物件为什么特殊；
- **重量**：人物动机、关系和场景是否具有与剧情相称的分量；
- **期待**：揭晓、获得、失败或承诺是否产生下一步牵引；
- **回报**：此前积累的危险、情绪或信息是否得到可感知的兑现；
- **余波**：结果是否在需要时进入人物关系、利益、声望或后续行动。

这些不是逐项检查表。一处编辑不需要同时证明所有效果，也不是每章都必须补齐所有效果。

## 3. 找到叙事牵引

真正可扩写的位置通常已有一个触发物：异常结果、关键物件、称谓、身体反应、错误判断、人物选择、胜负或代价。先确定读者正在看什么，再决定是否需要讲述。

不要先决定“补一段设定”，再寻找插入位置。若删除新增内容后，人物看法、局势估值和读者期待都没有变化，它多半只是附加资料。

## 4. 重织而非插入

一次完整重织包含：

1. 触发：原文中什么东西生出了讲述需要；
2. 展开：知识、往事、生活或判断怎样获得自身的小型叙事运动；
3. 交换：展开内容怎样改变气氛、价值、选择或危险；
4. 回流：正文怎样重新回到当前动作，并让后文因此不同。

因此编辑可以修改扩写点前后数段。不得把生成好的说明段原封不动夹进正文，再用一句“想到这里”机械返回。

## 5. 选择承载方式

根据项目声音和当前场景选择叙述者判断、人物推断、回忆、传闻、旁观者、对话、资料、习俗、交易或事后复盘。选择关系由当前人物的知识、身份、欲望和叙述距离决定，不由固定模板决定。

长扩写不天然破坏节奏。只要每一层仍被当前问题牵引，它可以走到过去、地方生活、群体利益或普遍人情。短说明若与人物和局势没有交换，同样会显得突兀。

## 6. 声音与中文表达

文风限制不只表现为词汇相似，还包括：

- 叙述者知道多少、愿意判断多少；
- 句子偏好断语、比喻、吐槽、冷判断还是人物推演；
- 严肃信息允许被多少日常、粗俗或幽默打断；
- 段落如何收束并把控制权交回现场。

修正翻译式语序、虚浮修饰、抽象名词堆叠和不自然对白时，优先恢复中文叙述的动作关系与口气。不要把所有句子改成同一种短句，也不要用成语和古风词汇制造表面本地化。

## 7. 文学性与功能拼接

功能可以分开诊断和生产：解释、爽点、回扣、升级、伏笔和读者提醒都可以成为编辑对象。文学整合负责让这些材料在视角、语气、动作和心理中重新获得生命。

目标不是消灭所有模块痕迹，也不是容忍裸露接缝，而是先允许功能性补写，再把它改成这部作品会自然说出的故事。完成扩写后主动压缩重复解释，让已被动作或形象证明的部分不再二次点题。

## 8. 禁止机械化

- 不要求每个异常都得到解释；
- 不要求每场战斗都命名招式或列出境界；
- 不要求每个场景都有历史、旁观者或风俗；
- 不把“人物真实情况下不会这样想”当成拒绝一切说明的理由；
- 不把样本中的比喻、句式、节奏或承载方式变成固定模板；
- 不为了增加字数扩写已经成立的段落。
