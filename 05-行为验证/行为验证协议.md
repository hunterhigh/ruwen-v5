# 行为验证协议

四项任务分别在全新隔离上下文运行，不能读取其他任务的输出：

1. 外部知识顾问围绕共同项目提出学习计划与初步材料机会，检查是否服务世界和剧情，而非回答孤立知识题。
2. 表现设计师只根据研究侧文学样本和共同项目形成项目声音候选，检查来源、例子和完整路线是否被剥离。
3. 小说作者只根据主角信息和场景事实写短场景，检查感知异常是否改变注意和信息组织，而非变成症状清单。
4. 小说作者只根据世界激活后的场景事实写短场景，检查驿道系统是否改变行动与社会含义，而非成为百科说明。

任务1和2只验证岗位边界。任务3和4只产生非正典效果样本，不作为文学质量胜出证据。所有结论分为通过、条件通过、失败或待用户确认。
